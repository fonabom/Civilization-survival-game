# Как обновить репозиторий на GitHub (сборка b13)

Это ZIP **с исходным кодом релизной сборки b13 «Всё сразу»**. Номеров версий нет:
сборка обозначается буквами и цифрами (`build.txt` -> `b13`).

Распакуйте архив поверх своей локальной копии репозитория и запушьте.

## Вариант 1 — автоматически

* Windows: двойной клик по `ЗАПУШИТЬ.bat`
* Linux/macOS: `bash ЗАПУШИТЬ.sh`

## Вариант 2 — вручную

```bash
# 1. распакуйте архив поверх папки с репозиторием (копировать с заменой)

# 2. убрать старый мусор
find . -name "__pycache__" -not -path "./.git/*" -prune -exec rm -rf {} +
rm -rf venv release_build launcher.log version.txt

# 3. закоммитить и запушить
git add -A
git commit -m "build b13: biomes and seasons (a living world), background music, a first-steps quest chain with F1 help and quality-of-life: rebindable keys, map waypoints, inventory sorting, chat channels"
git push
```

## После пуша — теги

Сборка (бета-канал, предрелиз):

```bash
git tag b13 && git push --tags
```

Релиз 1.0.0 (стабильный канал) — когда бета обкатана:

```bash
git tag 1.0.0 && git push --tags
```

GitHub Actions (`.github/workflows/release.yml`) по тегу прогонит тесты, соберёт
`Civilization_Beta.zip`, клиентский и серверный архивы, exe-файлы и установщик, и
опубликует релиз. Лаунчер качает релиз с выбранного канала.

## Что нового в b13 (коротко)

* **Биомы.** Шесть биомов: луга, лес, пустыня, снежная тундра, болото, пещеры.
  Деревья — лес и болото, грибы — болото и пещеры, руда — пещеры и пустыня,
  овцы — луга, волки и медведи — лес и тундра. По болоту (0.8) и тундре (0.85)
  ходить медленнее, по песку (1.05) быстрее; те же числа считает клиент, поэтому
  шаг не «откатывается».
* **Сезоны.** Весна → лето → осень → зима, каждый по `days_per_season` дней.
  Весной лес отрастает (×1.25), осенью грибы и ягоды (×1.35), зимой всё замирает
  (×0.45), ходьба медленнее (×0.92), дождь сменяется туманом. В HUD — день и
  сезон, зимой идёт снег. Выключается на сервере: `"seasons": false`.
* **Музыка.** День, ночь, пещера, бой; свои треки — `assets/music/` или ресурс-пак
  (`day_*.ogg`, `night_*.ogg`, ...). В настройках две новые строки.
* **Первые шаги.** Цепочка 10 целей с проверкой по настоящему состоянию игры,
  прогресс в `config.json`, сброс в настройках, кнопка справки `F1` (4 страницы).
* **Удобства.** Переназначение любых клавиш (занятая клавиша не отбирается молча —
  можно поменять действия местами), точки на карте (`P` / `Shift+P`), сортировка
  инвентаря (`O`) и заполнение хотбара (`Shift+O`), каналы чата (`/g`, `/l`,
  `/c`, `/w <имя>`), локали en/pl/ru — 734 ключа в каждой.
