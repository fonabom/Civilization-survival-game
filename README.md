# Civilization Survival Game (beta)

Многопользовательская survival/RTS-песочница на Python + pygame: рубим лес, строим
город, исследуем технологии (индустриализация, химия) и воюем за территорию.
Один игрок запускает сервер, остальные подключаются по локальной сети.

A small multiplayer survival/civilisation game written in Python + pygame.
One player hosts the server, everyone else joins over LAN.

Языки интерфейса: **English / Polski / Русский** (переключаются в меню и в настройках).

---

## Быстрый старт

1. Установите Python 3.10+ (https://www.python.org/downloads/).
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

### Хост (сервер)

```bash
python run_server.py
```

Сервер напечатает адрес, который надо передать друзьям, например
`192.168.1.5:5555` (по умолчанию порт 5555).

Полезные параметры:

```bash
python run_server.py --port 6000 --save saves/friends.json   # другой порт и сейв
python run_server.py --no-save                                # игра без сохранения
python run_server.py --no-accounts                            # без аккаунтов, только гости
CIV_PORT=6000 python run_server.py                            # то же через переменные среды
```

**Мир** сохраняется в `saves/world.json` каждые 60 секунд, при остановке сервера
(Ctrl+C) и по команде `/save` в чате. `/wipe` начинает мир заново.

**Аккаунты** (регистрация/вход из главного меню) лежат в `server_data/accounts.json`:
пароли хранятся только как PBKDF2-HMAC-SHA256 с солью, прогресс игрока (инвентарь,
HP, позиция, предмет в руке) возвращается при следующем входе. Гость ничего не
сохраняет между сессиями.

### Игрок

```bash
python run_client.py
```

Введите адрес хоста (`host:port`), затем либо **CREATE ACCOUNT** + **LOG IN**, либо
**PLAY AS GUEST**. Тот же клиент можно запускать много раз на одном ПК для теста.

### Лаунчер (необязательно)

```bash
python launcher.py
```

`PLAY` запускает игру, `Check updates` — обновление. Лаунчер ищет новую сборку
через GitHub в таком порядке:

1. последний GitHub Release репозитория (файл `Civilization_Beta.zip`);
2. архив репозитория (`codeload.github.com`, ветка `main`) — работает даже без релиза;
3. свои ссылки из `launcher_config.py` (`UPDATE_URL_VERSION` / `UPDATE_URL_ZIP`).

Перед установкой лаунчер делает резервную копию (`backup_before_update_…`) и
обновляет `build.txt`. Свой сервер обновлений можно поднять одной командой
`python -m http.server 8000` и прописать ссылки в `launcher_config.py`.

## Сборка (build) вместо версий

Номера версий не используются: сборка обозначается **буквами и цифрами** —
`b8`, `b9`, `b10`. Текущая сборка лежит в `build.txt`, сравнение числовое
(`b10` новее `b9`).

```bash
python tools/bump_build.py --commit   # b10 -> b11 и коммит
git tag b10 && git push --tags        # тег запускает GitHub Action с релизом
```

Workflow `.github/workflows/release.yml` по тегу `b*` прогоняет тесты, собирает
`Civilization_Beta.zip` и публикует релиз — именно его скачивает лаунчер.

## Что нового в b13 «Всё сразу»

Релизная сборка: к релизу 1.0.0 игра получила сразу всё, что было в плане, —
живой мир (биомы и сезоны), музыку, обучение с первых секунд и удобства.

### Мир стал разным: биомы
- Карта делится на **шесть биомов**: луга, лес, пустыня, снежная тундра, болото
  и пещеры (6 % пещер, у каждой свой характер). Биомы не «нарисованы» — они
  рождаются из двух сглаженных полей шума и видны и на земле, и на мини-карте.
- Ресурсы и животные живут по биомам: **деревья** — лес (216 стволов) и болото,
  **грибы** — болото и пещеры, **руда** — пещеры и пустыня, **овцы** — луга,
  **волки и медведи** — лес и тундра.
- Ходить по миру тоже по-разному: болото 0.8 скорости, тундра 0.85, лес 0.95,
  пустыня 1.05, луга 1.0. Те же числа считает и клиент, поэтому шаг игрока
  не «резинкой» откатывается (проверено живым тестом: 50 шагов, 0 расхождений).

### Сезоны
- Год идёт по кругу: **весна → лето → осень → зима**, каждый сезон длится
  `days_per_season` игровых дней (по умолчанию 3), сутки — `day_length` секунд.
- Весной лес отрастает быстрее (×1.25), осенью всюду грибы и ягоды (×1.35),
  зимой почти ничего не растёт (×0.45), земля мёрзлая — все двигаются медленнее
  (×0.92), а погода берётся из «зимнего мешка»: дождь меняется на туман.
- В HUD видно **день и сезон**, при смене приходит уведомление, зимой идёт снег,
  а картинка получает легкий оттенок сезона. Выключить всё это можно на сервере:
  `"seasons": false` — и числа вернутся к прежним.

### Музыка и звуки
- В игре появилась **фоновая музыка**: спокойный день и тихая ночь, отдельные
  треки для пещеры и боя (включается, когда рядом враг или мало HP). Свои файлы
  кладутся в `assets/music/` или в ресурс-пак — см. «Своя музыка» ниже.
- Громкость музыки и её выключатель — в настройках (две новые строки рядом со
  звуком). Треки сгенерированы `tools/make_sounds.py` вместе со звуками.

### Первые шаги (обучение)
- Новая **цепочка из 10 шагов** для новичка: оглядеться, дерево, первый
  инструмент, камень, верстак, костёр, еда, факел, свой город, первая зима.
  Шаги закрываются по настоящим действиям, прогресс хранится в `config.json`
  и продолжается со следующего входа. В левом верхнем углу видно текущий шаг и
  прогресс («Первые шаги: 3/10»), кнопка «Начать первые шаги заново» — в
  настройках.
- **F1 — справка** из четырёх страниц: первые шаги, управление (с текущими
  клавишами), мир (биомы, сезоны, голод, вода) и города (роли, налоги, война).

### Удобства
- **Клавиши можно переназначить.** Настройки → «Управление»: нажми на строку и
  нажми нужную клавишу. Занятая клавиша не отбирается молча — игра скажет, кто
  её занял, и предложит **поменять действия местами**. Есть сброс к стандартным.
- **Точки на карте.** `P` — поставить точку там, где стоишь, `Shift+P` — убрать
  ближайшую. Точки видны на мини-карте, а справа снизу — стрелка и расстояние до
  ближайшей. Они хранятся отдельно для каждого сервера (`waypoints.json`).
- **Сортировка инвентаря.** `O` переключает порядок (по категориям → по
  количеству → по названию), `Shift+O` — разложить инструменты и еду в хотбар.
- **Каналы чата.** `/g` — всем, `/l` — только рядом (12 тайлов), `/c` — своей
  стране, `/w имя текст` — одному человеку. Голые `/g`, `/l`, `/c` переключают
  канал насовсем, каждая строка чата помечена каналом и своим цветом.

### Клавиши b13

| Клавиша | Что делает |
| --- | --- |
| `P` | поставить точку на карте |
| `Shift`+`P` | убрать ближайшую точку |
| `O` | сменить порядок в инвентаре |
| `Shift`+`O` | разложить инструменты и еду в хотбар |
| `F1` | справка (первые шаги, управление, мир, города) |
| `/g`, `/l`, `/c`, `/w` | канал чата: всем, рядом, стране, шёпот |

Все остальные клавиши — те же, что в b11/b10, и любую из них можно сменить в
настройках.

## Что нового в b12 «Релизная инженерия»

Начали с идеи №9 из плана 1.0.0: сборка, установка и обновление.

- **Сервер и клиент — теперь разные сборки.** Из одного репозитория собираются
  три архива: `Civilization_Client_<build>.zip` (игра), `Civilization_Server_<build>.zip`
  (сервер) и `Civilization_Beta.zip` (оба вместе — его качает лаунчер). Серверу
  **не нужен pygame** и вообще никаких библиотек: его можно поднять на любом VPS,
  а код игры и код сервера не тянут друг друга вообще (это проверяется тестами).
  Убедиться в этом можно так:

  ```bash
  python check_server.py --forbid-pygame     # «сервер работает без pygame»
  ```

- **Установщик.** Windows: `Civilization-Setup-b12.exe` — обычная установка
  (папка, ярлык на рабочем столе и в «Пуск», удаление через «Установка и удаление
  программ»), Python ставить не нужно. Внутри два файла: `Civilization.exe` (игра)
  и необязательный `CivilizationServer.exe` (сервер для друзей). Linux/macOS и
  те, у кого есть Python:

  ```bash
  python installer/install.py              # окно установки
  python installer/install.py --silent --target ~/Civilization --install-deps
  python installer/install.py --uninstall --target ~/Civilization
  ```

  Установщик понимает `.zip`, папку репозитория и целую папку с игрой; серверный
  архив по ошибке не поставит (скажет, что это не клиент).

- **Каналы обновлений и откат.** В лаунчере появился выбор канала: **стабильная**
  (только настоящие релизы) и **бета** (свежие сборки `bNN`, они публикуются как
  предрелизы). Перед каждой установкой обновления лаунчер сохраняет текущую
  версию, поэтому есть кнопка **«Откатить»** (хранится 3 предыдущих версии).
  Те же действия из командной строки: `python launcher.py --rollback`,
  `python launcher.py --check --channel stable`.

- **Настройки больше не пропадают.** Появился `shared/paths.py`: игра сама решает,
  где читать данные (рядом с exe или в папке проекта) и куда писать настройки.
  Установленная в `Program Files` игра пишет конфиг в `%APPDATA%\Civilization`,
  а не рядом с собой, — раньше на этом всё бы падало с ошибкой доступа.

- **CI собирает всё** по тегу: тесты → три архива → `exe`-файлы → установщик.
  Теги `bNN` публикуются как предрелизы (бета-канал), тег вида `1.0.0` станет
  обычным релизом (стабильный канал). Подробности — в `installer/README.md`.

### Что это значит для тебя

| Что нужно | Что делать |
| --- | --- |
| Играть | `python run_client.py` или ярлык после установки |
| Поднять сервер для друзей | распаковать `Civilization_Server_*.zip`, `python run_server.py` |
| Проверить, что сервер живой | `python check_server.py --forbid-pygame` |
| Сделать релиз | `python tools/bump_build.py --commit && git push && git tag b13 && git push --tags` |
| Откатить обновление | кнопка «Откатить» в лаунчере |

## Что нового в b11 «По воде и в человеческом облике»

- **По воде можно ходить:** игрок входит в воду и идёт по ней медленно — 40 %
  скорости (`swim_speed` в настройках сервера). Утонуть нельзя, на берег выйти
  можно всегда. Мост (скорость 1.2) остаётся быстрым путём, дорога — 1.35,
  камень не пропускает никого. При первом входе в воду приходит одна подсказка.
  Ключ `swim: false` возвращает старое правило «вода — стена».
- **Игрок — человечек, а не куб:** новый спрайт `assets/player.png` (голова, тело,
  руки, ноги), свой цвет у каждого игрока, поворот в сторону движения, покачивание
  на ходу, круги на воде при плавании. Свой персонаж из ресурс-пака подменяется
  одной картинкой.
- **Мост теперь ставится по воде:** клиент показывал «здесь нельзя строить» на
  реке, потому что его проверка места считала воду стеной. Клиент и сервер
  теперь читают одно правило: камень — никогда, мост — только по воде, всё
  остальное — только по земле.
- **Строить через стены больше нельзя:** проверка территории смотрела лишь на
  тайл игрока, и чужак мог встать у стены и поставить башню внутри города;
  теперь проверяется вся площадка постройки, а сообщение называет тот город,
  который запретил.
- **Исправлено дублирование в инвентаре:** один и тот же стак больше не рисуется
  сразу и в сетке, и в ряду хотбара — сетка показывает то, чего нет в хотбаре.
- **Починен звук из ресурс-пака:** папка `sounds/` в паке теперь действительно
  читается, и можно класть свои `.wav`, `.ogg` или `.mp3` (см. раздел «Свои
  звуки» ниже).
- **Подсказка для новичка:** первая строка обучения объясняет, что ты — человечек
  в центре экрана и ходишь на `WASD`; напоминание про еду: `Q`.

### Клавиши b11

| Клавиша | Действие |
| --- | --- |
| `WASD` в воде | плыть (медленно, но можно) |
| `Q` | съесть лучшую еду из сумки |
| ПКМ по еде в инвентаре | съесть конкретную еду |
| `bridge` + ЛКМ по воде | мост: только по воде, скорость 1.2 |

## Что нового в b10 «Цивилизация»

- **Роли в городе:** лидер, старейшина, строитель, воин, гражданин. Лидер раздаёт
  роли кликом по жителю в меню `V` или командой `/role <имя> <роль>`. Внутри
  города строить и пользоваться складом могут только строитель и старейшина,
  исследования — старейшина; воин получает **+10 %** к урону в ближнем бою.
- **Налоги и городской фонд:** лидер ставит налог 0–40 % (в меню `V` кнопками
  `-/+` или `/tax 40`). Налог берётся с добычи внутри территории города и копится
  в фонде; город сначала тратит фонд, а потом деньги строителя, так что налоги
  строят город. Команда `/city` показывает тир, налог, фонд и роли.
- **Осада и захват:** ратушу можно ломать только на войне. Пока она держится,
  город получает предупреждение «под осадой». Разбитая ратуша отдаёт город
  стране победителя: прежний лидер изгоняется, должности упраздняются, фонд
  ложится в карман атакующего. Одиночка без страны может только разграбить город
  (фонд + минус один тир).
- **Победа в партии:** владеть **всеми** городами карты или построить **чудо
  света** (`wonder`: 3×3, 2000 HP, 400 дерева + 300 камня + 150 железа + 100
  золота, технология `industrialization` и эпоха индустрии, строит лидер города).
  Победитель объявляется всему серверу, на экране — баннер.
- **Эпохи:** каменный век → бронзовый → железный → индустрия → электричество;
  эпоха страны видна в меню `V` и в HUD, чудо света требует эпоху индустрии.
- **Медицина:** технология `medicine` открывает больницу, бинт и аптечку. Аптечка
  лечит 45 HP и снимает отравление, бинт — 15 HP (клавиша `H`), больница лечит
  всех вокруг по 6 HP каждые 5 с.
- **Электричество:** технология `electricity` открывает генератор и лампу; лампа
  светит только в 400 px от генератора.

### Клавиши b10

| Клавиша | Действие |
| --- | --- |
| `H` | использовать аптечку или бинт |
| `B` | открыть крафт сразу на вкладке построек |
| `V` → клик по жителю | сменить роль (только лидер города) |
| `V` → `-` / `+` у налога | налог 0–40 % (только лидер города) |
| `/role <имя> <роль>` | выдать роль (`/tax`, `/city` — налог и сводка) |

## Что нового в b9 «Мир живой»

- **Вода и мосты:** озёра и река на карте, вода не пропускает; `bridge`
  (4 дерева, технология masonry) — единственная постройка на воде и переход
  через неё. Миникарта показывает воду синим, пещеры — тёмным.
- **Пещеры:** семь пещер с входом, внутри темно, растут грибы, лежат глубокие
  жилы (железо, золото, уголь, сера) — добыча внутри даёт **×2** ресурсов.
- **Рыбалка:** удочка (3 дерева + 2 нитки, agriculture). У воды нажми `E` —
  поймаешь 1–2 рыбы; рыба жарится в жареную рыбу (`cook_fish`).
- **Погода стала механикой:** дождь замедляет ходьбу и вдвое ускоряет рост ферм,
  туман приглушает свет факелов (ключ `weather` в настройках сервера).
- **Стаи волков и медведи:** волки ходят по 3–5 и мстят за раненого сородича,
  в пещерах живут медведи (140 HP).
- **Дипломатия:** страны воюют, мирятся и заключают союзы (кнопки в меню `V`
  или `/war /peace /ally <страна>`). В мире никто не может ранить ни игроков,
  ни их постройки.
- **Рынок:** постройка `market` (60 дерева + 20 камня, logistics) и окно `Y`:
  выставляй «отдаю X за Y», покупай чужое. Оплата приходит в сумку, на склад
  города или выдаётся при следующем входе, если продавец был не в сети.

### Клавиши b9

| Клавиша | Действие |
| --- | --- |
| `Y` | рынок: объявления и своё предложение |
| `E` у воды с удочкой | забросить удочку |
| ПКМ по стране в меню `V` | выбрать страну для дипломатии |
| `/trade` | список объявлений в чате |
| `/war /peace /ally <страна>` | дипломатия для лидера страны |

## Что нового в b8

- **Выживание:** голод падает со временем, при 0 HP уходит, при сытости выше
  70 — медленно восстанавливается; еда разная (яблоки, ягоды, хлеб, жареное
  мясо, рыба), сырое мясо иногда отравляет.
- **Износ и броня:** прочность инструментов (полоска в хотбаре и инвентаре,
  сломанный инструмент пропадает), железная и кожаная броня на 4 слота, щит,
  разные виды оружия с уроном, дальностью и патронами.
- **Животные:** овцы, коровы, куры и волки; охота даёт мясо, кожу, шерсть и
  нитки, приручение (ПКМ с мясом) делает питомца, ночью волки охотятся.
- **Мир:** смена дня и ночи, погода (ясно/дождь/туман), свет от факелов и
  костров, прочность построек, двери, дороги, сундуки и склады (содержимое
  видит только владелец и его город).
- **Прогресс:** задания и достижения с наградами (клавиша `K`), статистика,
  уровни города до 3-го и технологии страны, открывающие здания и рецепты.
- **Удобства:** мини-карта (`M`), звуки с громкостью в настройках, подсказки для
  новичков, всплывающие числа урона, команды чата `/who /online /where /time
  /day /msg <имя> <текст>`.
- **Настройки сервера** в `server_config.json` (или `--config <файл>`): `pvp`,
  `day_length`, `hunger_rate`, `resource_rate`, `durability`, `animals`,
  `wolves`, `weather`, `animal_respawn`, `start_kit`, `max_players`,
  `save_interval` (+ b10: `taxes`, `victory`).

### Предмет в руке

Всё, что можно делать, зависит от предмета в руке: им рубят дерево и камень
(эффективность), им же атакуют (`sword`, `iron_sword`, пистолет расходует
`ammo`). Пустая рука бьёт слабо. Хотбар заполняется автоматически теми
предметами, которые есть в инвентаре; раскладывать вручную можно в инвентаре
(`I`) — клик по предмету, затем по слоту хотбара.

### Крафт и постройки

- Крафт привязан к станции: топор/кирка/меч/патроны — на `crafting_table`,
  железные инструменты и пистолет — на `advanced_workbench`, порох — на
  `chemical_plant`. Меню само пишет «нужна такая-то станция».
- ЛКМ — скрафтить 1, ПКМ — сразу 5, Shift+ЛКМ — максимум из имеющихся ресурсов.
- Постройки во вкладке Buildings: выберите здание (включается режим «призрака»)
  и кликните по клетке. Ставить можно на расстоянии до 8 клеток; игра не даст
  поставить здание друг на друга, на игрока или без нужной технологии.

### Настройки

Кнопка `SETTINGS` в главном меню или `Esc` → Settings в игре: язык, ресурс-пак,
полноэкранный режим, показ FPS/отладки, запоминание логина, сброс хотбара и
сброс всех настроек.

## Ресурс-паки

Пак — это папка `resourcepacks/<имя>/` с `pack.json` и `textures/*.png`.
Отсутствующие текстуры берутся из встроенных `assets/`, так что можно положить
в пак только то, что хотите изменить.

```bash
python tools/make_resourcepack.py --all      # создать 4 пака (neon, dark, desert, invert)
python tools/make_resourcepack.py --name mypack --style desert
```

Готовые паки выбираются в настройках; игра применит их сразу после переключения.

## Свои звуки

Звуки не вшиты в код: игра ищет файлы по именам в `assets/sounds/`, а ресурс-пак
может положить свои в `resourcepacks/<пак>/sounds/` (пак имеет приоритет).

1. Возьмите свои файлы (обычные `.wav`, `.ogg` или `.mp3` — конвертировать не надо)
   и переименуйте их в имена из списка ниже.
2. Положите их в `assets/sounds/` (заменят встроенные) **или** создайте папку
   `resourcepacks/mysounds/sounds/` с файлом `resourcepacks/mysounds/pack.json`:

   ```json
   {"name": "My sounds", "author": "me", "description": "нормальные звуки"}
   ```

3. Выберите пак в настройках игры (`Esc` → Settings → ресурс-пак) — звуки
   подхватятся сразу, без перезапуска.

| Имя файла | Когда играет |
| --- | --- |
| `chop.wav` | рубка дерева |
| `mine.wav` | добыча камня и руды |
| `hit.wav` | удар по игроку или постройке |
| `hurt.wav` | вам нанесли урон |
| `shot.wav` | выстрел из пистолета |
| `bow.wav` | выстрел из лука |
| `craft.wav` | крафт |
| `build.wav` | постройка |
| `break.wav` | постройка разрушена |
| `eat.wav` | еда |
| `step.wav` | шаг |
| `pickup.wav` | подобран предмет |
| `task.wav` | задание выполнено |
| `death.wav` | смерть игрока |
| `night.wav` | наступает ночь |
| `rain.wav` | начинается дождь |

Файл можно положить только для нужных звуков — остальные останутся встроенными
(генератор встроенных: `python tools/make_sounds.py --force`). Громкость каждого
звука задана в `client/audio.py` (`DEFAULT_VOLUMES`), общая — в настройках игры.

## Своя музыка

Музыка ищется так же, как звуки: сначала в ресурс-паке, потом в `assets/music/`.
Имя файла задаёт настроение, поэтому свои треки просто называются по шаблону
`<настроение>_любое_имя.ogg`:

| Настроение | Когда играет |
| --- | --- |
| `day_*` | день |
| `night_*` | ночь |
| `cave_*` | в пещере |
| `battle_*` | рядом враг или мало здоровья |
| `calm_*` | запасной вариант, если для настроения нет своего файла |

Подходят `.ogg`, `.mp3` и `.wav`. В репозитории лежат два коротких встроенных
трека (`day_calm.wav`, `night_calm.wav`, ~20 секунд), сгенерированные
`python tools/make_sounds.py`; `--force` перезаписывает и звуки, и музыку.
Громкость музыки и её выключатель — в настройках.

## Прогрессия

дерево/камень → верстак (`crafting_table`) → топор и кирка → ратуша
(`town_center`, требует быть лидером города) → тир города 2 → железо/золото/уголь/
нефть → `research_table` → технологии `industrialization` (двойная плавка,
бур/насос/завод), `chemistry` (химзавод), `medicine` (больница, аптечка),
`electricity` (генератор, лампа) → эпоха индустрии → **чудо света** или захват
всех городов: партия заканчивается победой одной страны.

## Структура проекта

```
client/       клиент pygame: меню, игровой цикл, сеть, UI (widgets + экраны), i18n, ресурс-паки
client/ui/    экраны: инвентарь, крафт, строительство, города, исследования, плавка, настройки
server/       авторитарный сервер: мир, города/страны, аккаунты, сохранения
shared/       общий код: протокол (длина + JSON), предметы, рецепты, постройки, build id
locales/      en.json / pl.json / ru.json (одни и те же ключи)
resourcepacks/ примеры паков текстур
tests/        pytest: протокол, мир, сквозные тесты сервера, аккаунты, лаунчер, smoke-тест клиента
tools/        сборка ZIP, bump_build, генератор ресурс-паков, headless-боты для проверок
```

Протокол: big-endian `uint32` длина + UTF-8 JSON. Состояние мира рассылается
клиентам 15 раз в секунду; разделы `resources` / `buildings` / `civs` — только
когда они изменились; инвентарь приходит только владельцу. Уведомления — пара
`{"key": "notify.built", "args": {...}}`, перевод делает клиент.

## Тесты

```bash
python -m pytest tests -q          # весь набор
python tools/headless_bots.py      # сквозная проверка: настоящий сервер + клиенты-боты
python tools/headless_bots.py --shots out/   # то же + скриншоты в out/
```

Тесты поднимают настоящий сервер на случайном порту и проверяют мультиплеер
(синхронизация, постройка, приватность инвентаря, «мусорные» пакеты), аккаунты,
автообновление лаунчера, а также прогоняют клиент без окна (SDL dummy).
`tools/headless_bots.py` — «живой» прогон: боты ходят, собирают, крафтят,
строят, дерутся, регистрируются и переподключаются после падения сервера.
